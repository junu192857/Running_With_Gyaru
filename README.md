# running-app

React Native(Expo) 러닝 앱. Android/iOS 대상.

## 핵심 설계 결정

- **목표 모드**: 거리 달리기 / 시간 달리기 중 선택, 카운트다운 5초 후 측정 시작
- **음성 안내(시스템 TTS)**: 구간 안내는 항상 거리 기준으로 통일 (예: 500m/1km마다). 완주 직전 안내는 목표 타입에 따라 분기 — 거리 목표는 완주 200m 전, 시간 목표는 완주 1분 전
- **GPS 처리**: 정확도 필터(20m) + 속도 이상치 필터(7m/s) + 정지 보정(2m 미만 이동 무시), haversine으로 누적 거리 계산, 페이스는 이동평균
- **일시정지**: GPS 리스너는 유지하되 거리/시간 누적에서 제외, 재개 직후 1~2개 포인트는 버퍼링
- **캐릭터 음성 응원(개인 소장용, 스토어 배포 안 함)**:
  - 마일스톤(구간/완주 직전) 멘트는 러닝 시작 직전에 미리 생성 후 로컬 캐싱 (LLM 텍스트 생성 + TTS + RVC 음성 변환, 서버리스 GPU 호출)
  - 구간 사이 일반 응원 멘트는 사용자가 설정한 간격(최소 2분)마다 실시간 생성
  - 두 경로 모두 재생 큐로 합쳐지며(마일스톤 우선), GPS 거리/페이스 계산과는 완전히 분리된 비동기 흐름이라 측정 정확도에 영향 없음
- **기록 저장**: SQLite. 세션당 날짜, 목표 타입/값, 실제 거리/시간, 평균 페이스, 완주 여부 저장
